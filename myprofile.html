Projects:


1. Water Level Detection System


Technology: C/C++ for STM32, Keil IDE, Bluetooth (HC-05), Ultrasonic Sensor


Designed and implemented a real-time water level monitoring system using the STM32F401 microcontroller. The project integrated ultrasonic sensors for accurate level detection, LED indicators for intuitive display, and Bluetooth for real-time communication. Also included remote pump control and automated overflow prevention mechanisms, offering a practical IoT-based solution for household or agricultural water management.



2. Emergency Coordination System


Technology: Python, Networking, Supabase (PostgreSQL BaaS)


Developed a Python-based emergency coordination platform inspired by DNS design. Implemented a peer-to-peer (P2P) communication model that allows civilians, responders, and administrators to report incidents, allocate resources, and coordinate during disasters. Supabase was used for backend data storage and retrieval, ensuring scalable and real-time support for emergency services.



3. Interactive Learning App for Kids


Technology: React, Node.js, PostgreSQL, Web Development, Data Visualization


Created a feature-rich educational platform tailored for children. It includes interactive games, video lessons, and adaptive learning modules. The app supports parent-child account systems, progress tracking, rewards, real-time leaderboards, and accessibility features like offline mode. REST APIs and modular backend architecture were implemented for scalability and smooth performance.
